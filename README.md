# React Gallery App

A dynamic image gallery built with React.js that fetches and displays images using an external API.

## Features
- Fetches images from an external API
- Dynamically displays gallery content
- Interactive user interface

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS
- API Integration

## How to Run
1. Clone this repository.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown in your terminal.
